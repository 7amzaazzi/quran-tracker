📖 مدرسة التفوق القرآنية — سجل متابعة الطلاب
ورماس – الوادي
تطبيق ويب متكامل لمتابعة أداء طلاب حلقة القرآن الكريم، مبني بـ HTML/CSS/JavaScript خالص مع Firebase كقاعدة بيانات سحابية.
✨ المميزات
• متابعة شاملة — تسجيل درجات الحفظ والتجويد والمراجعة والحضور والسلوك لكل جلسة
• مزامنة فورية — البيانات محفوظة على Firebase وتتزامن تلقائياً بين الحاسوب والهاتف
• لوحة إحصائيات — ملخص فوري لمتوسط الأداء والحضور وأفضل الطلاب
• أرشفة الطلاب — إخفاء وتجميد سجل الطلاب المتوقفين مع إمكانية الاسترجاع
• حسابات أولياء الأمور — كل ولي أمر يرى سجل ابنه فقط
• نظام تسجيل دخول آمن — Firebase Authentication يمنع أي تعديل غير مصرح
• واجهة عربية RTL — مصممة بالكامل للغة العربية مع دعم الوضع الليلي
• يعمل بدون إنترنت — Firebase يحفظ التغييرات محلياً ويزامنها عند العودة
